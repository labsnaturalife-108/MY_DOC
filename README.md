# MY_DOC — Персональный медицинский AI-ассистент

Интеллектуальная система ведения пациентов, анализа лабораторных и инструментальных исследований с векторным поиском (RAG) и мультимодельным чатом в стиле современных ИИ-ассистентов.

---

## 🌟 Основные возможности

1. **Электронный кабинет пациента (Медкарта):**
   - ФИО, возраст, пол, рост, вес с автоматическим расчетом индекса массы тела (ИМТ).
   - Приоритетный учет **критических аллергий и непереносимостей**.
   - Хронические заболевания и актуальный список принимаемых медикаментов и БАДов.

2. **Структурированные папки документов:**
   - 🧪 **Лабораторные анализы** (кровь, гормоны, биохимия).
   - 🔬 **Инструментальные исследования** (УЗИ, МРТ, КТ, ЭКГ, Рентген).
   - 📋 **Консультации и выписки** (заключения врачей, эпикризы).
   - 📚 **База знаний и литература** (научные статьи, книги, протоколы лечения).

3. **Векторный поиск RAG (ChromaDB + Эмбеддинги):**
   - Загруженные PDF, TXT и MD документы автоматически векторизуются и разбиваются на смысловые фрагменты.
   - Изолированные векторные коллекции по каждому пациенту.
   - В чате ИИ предоставляет **кликабельные сноски на первоисточники** и цитаты из загруженных документов.

4. **Автоматический парсинг и динамика анализов:**
   - Распознавание ключевых биомаркеров из загруженных файлов (ферритин, витамин D, гемоглобин, ТТГ, глюкоза, холестерин и др.).
   - Интерактивные графики динамики показателей по времени с отображением референсных диапазонов (норма, повышен, понижен).

5. **Мультимодельный хаб (Локальные и облачные нейросети):**
   - **Локальные модели:** Подключение через **LM Studio** (`http://localhost:1234/v1`) или **Ollama** для 100% конфиденциальности без отправки данных пациента в сеть.
   - **Облачные API:** OpenAI (GPT-4o, GPT-4o Mini), Anthropic Claude 3.5 Sonnet, Google Gemini 1.5/2.0, DeepSeek V3/R1, xAI Grok, Qwen.
   - **Встроенный демо-доктор:** Работает из коробки без сторонних ключей для мгновенного тестирования.

## 🚀 Быстрый старт

### Требования
- Python 3.10+
- Node.js 18+

### Запуск одной командой
В корне проекта выполните:
```bash
./run.sh
```

После этого откройте:
- **Веб-интерфейс:** [http://localhost:3000](http://localhost:3000)
- **Интерактивная документация API:** [http://localhost:8000/docs](http://localhost:8000/docs)

## 📁 Структура проекта

```
MY_DOC/
├── backend/                  # FastAPI бэкенд
│   ├── data/                 # SQLite база данных и векторные коллекции ChromaDB
│   ├── database.py           # Конфигурация SQLAlchemy
│   ├── models.py             # Модели БД (Пациенты, Документы, Анализы, Чаты)
│   ├── schemas.py            # Pydantic схемы валидации
│   ├── parser.py             # Парсер PDF и экстрактор биомаркеров
│   ├── rag_engine.py         # Векторное RAG-хранилище ChromaDB
│   ├── llm_hub.py            # Мультимодельный коннектор (LM Studio, API)
│   ├── main.py               # REST API и SSE стриминг сообщений
│   └── requirements.txt
├── frontend/                 # Next.js (App Router, Tailwind CSS, Lucide)
│   ├── src/
│   │   ├── app/              # Страницы и глобальные стили
│   │   ├── components/       # UI компоненты (Sidebar, PatientCard, ChatView, ...)
│   │   └── lib/api.ts        # Клиент взаимодействия с бэкендом
│   └── package.json
├── run.sh                    # Скрипт одновременного запуска бэкенда и фронтенда
└── README.md
```

## 🔒 Конфиденциальность и безопасность

- Вся медицинская информация и файлы по умолчанию хранятся локально на вашем компьютере (`backend/data/`).
- При использовании локального LM Studio данные пациента не передаются третьим лицам.
